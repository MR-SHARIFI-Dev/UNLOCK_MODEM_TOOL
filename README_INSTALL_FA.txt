راهنمای استفاده از قالب GitHub حرفه‌ای

۱. فایل ZIP را باز کن.
۲. محتویات داخل پوشه را روی ریپازیتوری GitHub قبلی جایگزین کن.
۳. اگر آدرس تلگرام فرق دارد، این مقدار را در README.md و docs/index.html تغییر بده:
https://t.me/UNLOCK_MODEM_TOOL

۴. برای فعال کردن صفحه تبلیغاتی:
GitHub Repository > Settings > Pages
Branch: main
Folder: /docs

۵. فعلاً فایل اپلیکیشن را آپلود نکن مگر نسخه تست‌شده نهایی آماده باشد.
وقتی آماده شد:
GitHub > Releases > Draft a new release
فایل exe/zip اپلیکیشن و SHA256 را قرار بده.

این قالب برای تبلیغ، معرفی پروژه، جذب کاربر به تلگرام و آماده‌سازی ریلیز عمومی ساخته شده است.
